| Item | Detail |
|---|---|

### Task 4 - Integrated GDP & Labour Force Analysis (Malaysia, 2023)

| Item | Detail |
|---|---|
| Datasets | `gdp_state_real_supply.csv` + `lfs_state_sex.csv` (DOSM) |
| Coverage | 16 Malaysian states/territories, year 2023 |
| Output | `outputs/merged_gdp_lfs_2023.csv` · 4 figures |

**Pipeline:**
1. Filter both datasets to 2023
2. Map GDP `Supra` → `W.P. Putrajaya` (join key harmonisation)
3. Pivot GDP long → wide (p0–p6 sector columns)
4. Pivot LFS long → wide (both/male/female metrics)
5. Inner join on `state` → 16-row integrated table
6. Compute sector proportions and GDP per employed person
7. Generate 4 visualisations + correlation analysis

**Key findings (2023):**
- Selangor leads GDP (~RM406,071 M); followed by W.P. Kuala Lumpur and Johor
- Unemployment highest in Sabah (7.5%) and W.P. Labuan (6.8%)
- Manufacturing share negatively correlated with unemployment (r ≈ −0.52)
- Mining share positively correlated with unemployment (r ≈ +0.50)
- Gender LFPR gap narrowest in urban, service-oriented states

**Data challenges:**
- GDP `Supra` ≠ `W.P. Putrajaya` in LFS → resolved by renaming before join; flagged in visualisations
- Negeri Sembilan missing male/female LFS rows in 2023 → excluded only from sex-specific plots
